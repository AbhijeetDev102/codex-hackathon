# Failure-pattern knowledge base

This folder is a small, hand-written retrieval corpus for the hackathon prototype.
It helps the application compare a verified run with known *patterns*; it does not
prove causality and it must never replace source-specific evidence.

`archetypes.json` contains eight broad failure patterns. `cases.json` contains twelve
brief comparison notes. The notes are deliberately neutral and high-level. Before any
case appears in a user-visible result, the pattern matcher must state similarities and
differences and cite the active research run's evidence.

These documents are product knowledge, not a source of verified facts for company
reports. They should be reviewed against reliable public sources before a production
use case.
